> Um projeto prático e direto ao ponto focado na implementação das três estruturas de dados mais essenciais da computação: Pilha, Fila e Lista Encadeada.

---

## 📖 Sobre o Projeto
Este repositório foi criado para consolidar conhecimentos fundamentais em Ciência da Computação. O objetivo é demonstrar o domínio sobre alocação de memória, manipulação de referências/ponteiros e lógica de programação através da construção de estruturas clássicas do zero.

---

## ⚙️ Estruturas Implementadas

### 1. Pilha (Stack)
Implementação baseada no princípio **LIFO** (Last In, First Out - O último a entrar é o primeiro a sair). Útil para algoritmos de reversão, navegação de histórico e chamadas de função.

### 2. Fila (Queue)
Implementação baseada no princípio **FIFO** (First In, First Out - O primeiro a entrar é o primeiro a sair). Amplamente utilizada em sistemas de agendamento, processamento assíncrono e filas de impressão.

### 3. Lista Encadeada (Linked List)
Estrutura linear dinâmica onde cada elemento (nó) aponta para o próximo. Diferente dos arrays estáticos, permite inserções e remoções eficientes sem a necessidade de realocar toda a memória.
